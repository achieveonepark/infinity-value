---
title: "Unity Samples"
---

The package includes importable samples through Unity Package Manager.

## Basic Usage

Shows construction, arithmetic, comparison, and display.

Import path:

```text
Samples~/Basic Usage
```

## Content Unit Names

Shows ScriptableObject-style content instances that own their own `InfinityValueUnitNames`.

Import path:

```text
Samples~/Content Unit Names
```

## Save Load

Shows simple PlayerPrefs persistence using `TryParse`.

Import path:

```text
Samples~/Save Load
```
