Infinity Value は、`long` の範囲をはるかに超える数値が必要なアイドル・インクリメンタルゲーム向け Unity パッケージです。

値はコンパクトな `(unitIndex, value)` ペアとして格納されるため、一般的な算術・比較演算でマネージドヒープへのアロケーションが発生しません。表示とパースには、組み込みの `A, B, C ... CZ` 単位名か、コンテンツタイプごとのカスタム `InfinityValueUnitNames` インスタンスを使用できます。

```csharp
using Achieve.InfinityValue;

var goldUnits = new InfinityValueUnitNames(new[]
{
    "", "K", "M", "B", "T", "Qa", "Qi"
});

InfinityValue gold = new InfinityValue(5_300_000_000L, goldUnits);
InfinityValue reward = new InfinityValue("12K", goldUnits);

gold += reward;

Debug.Log(gold.ToString()); // 5.30B
```

## 特徴

- Unity ランタイムコード向けの構造体ベースの大きな数値型
- 算術演算: `+`, `-`, `*`, `/`
- 比較演算: `==`, `!=`, `<`, `>`, `<=`, `>=`
- `InfinityValueUnitNames` によるインスタンスごとの単位名
- `TryParse` による文字列パース
- Unity の Newtonsoft パッケージがインストールされている場合のオプション JSON コンバーター
- `Samples~` にインポート可能な Unity サンプルを同梱
