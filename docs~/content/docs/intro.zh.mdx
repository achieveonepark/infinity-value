# Infinity Value

Infinity Value 是一个 Unity 包，专为需要远超 `long` 范围的超大数值的放置类和增量类游戏设计。

值以紧凑的 `(unitIndex, value)` 对形式存储，因此常见的算术和比较运算不会产生托管堆分配。显示和解析可使用内置的 `A, B, C ... CZ` 单位名称，或为每种内容类型定制 `InfinityValueUnitNames` 实例。

```csharp
using Achieve.InfinityValue;

var goldUnits = new InfinityValueUnitNames(new[]
{
    "", "K", "M", "B", "T", "Qa", "Qi"
});

InfinityValue gold = new InfinityValue(5_300_000_000L, goldUnits);
InfinityValue reward = new InfinityValue("12K", goldUnits);

gold += reward;

Debug.Log(gold.ToString()); // 5.30B
```

## 特性

- 面向 Unity 运行时代码的基于结构体的大数值类型
- 算术运算：`+`、`-`、`*`、`/`
- 比较运算：`==`、`!=`、`<`、`>`、`<=`、`>=`
- 通过 `InfinityValueUnitNames` 支持按实例定义单位名称
- 使用 `TryParse` 进行字符串解析
- 安装 Unity Newtonsoft 包后可使用可选的 JSON 转换器
- `Samples~` 中包含可导入的 Unity 示例
