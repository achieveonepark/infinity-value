# Unity 샘플

패키지에는 Unity Package Manager를 통해 임포트할 수 있는 샘플이 포함되어 있습니다.

## 기본 사용법

생성, 산술, 비교, 표시 방법을 보여줍니다.

임포트 경로:

```text
Samples~/Basic Usage
```

## 콘텐츠 단위 이름

자체 `InfinityValueUnitNames`를 소유하는 ScriptableObject 스타일 콘텐츠 인스턴스를 보여줍니다.

임포트 경로:

```text
Samples~/Content Unit Names
```

## 저장 및 불러오기

`TryParse`를 활용한 간단한 PlayerPrefs 영속성을 보여줍니다.

임포트 경로:

```text
Samples~/Save Load
```
