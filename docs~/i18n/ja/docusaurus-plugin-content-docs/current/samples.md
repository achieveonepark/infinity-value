# Unity サンプル

パッケージには Unity Package Manager からインポートできるサンプルが含まれています。

## 基本的な使い方

値の作成、算術演算、比較、表示を示します。

インポートパス:

```text
Samples~/Basic Usage
```

## コンテンツ単位名

自前の `InfinityValueUnitNames` を持つ ScriptableObject スタイルのコンテンツインスタンスを示します。

インポートパス:

```text
Samples~/Content Unit Names
```

## セーブ＆ロード

`TryParse` を使ったシンプルな PlayerPrefs 永続化を示します。

インポートパス:

```text
Samples~/Save Load
```
