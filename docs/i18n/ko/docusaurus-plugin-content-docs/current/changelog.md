# 변경 내역

## 미출시

- Docusaurus 사이트로 문서 재구성
- 콘텐츠별 단위 이름 인스턴스를 위한 `InfinityValueUnitNames` 추가
- `InfinityValueUnitNames`를 허용하는 생성자 및 `TryParse` 오버로드 추가
- `Samples~`에 Unity Package Manager 샘플 추가

## 1.1.0 — 2026-05-23

- 내부 슬롯 순서가 다른 값의 의미적 동등성 및 해싱 수정
- 뺄셈 borrow 동작 및 음수 결과 클램핑 수정
- `TryParse`, `Zero`, `One`, double 연산 및 double 변환 추가

## 1.0.1 — 2026-01-04

- 내부 구조 최적화를 통한 GC 압력 감소

## 1.0.0 — 2024-09-17

- 최초 릴리스
